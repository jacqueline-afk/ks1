# Kanaka Skills Loops

A single page that draws three Kanaka Skills loops (Makawalu, Hoa Paio, Kūpaʻa) for one student.

The page holds no student data. It reads which segments are filled from the link:

    https://YOUR-GITHUB-USERNAME.github.io/kanaka-loops/?f=1.1,1.3,2.3&p=3.3

f = filled segments, p = segments pending kumu confirmation. Add ?demo=1 to preview every loop closed with its badge.
